# Terraform Associate Notes

Personal study notes for the **HashiCorp Certified: Terraform Associate (003)** exam.

## Exam Overview

| | |
|---|---|
| **Duration** | 60 minutes (extension available for non-native English speakers) |
| **Format** | Online, proctored |
| **Cost** | $70.50 — no free retake |
| **Valid for** | 2 years |
| **Results** | Immediate |

### Question Format

- Multiple choice (single answer)
- Multiple select — the question states the exact number of options to choose
- True / False

## Exam Objectives

- [[01 - Terraform Fundamentals]] — What is Terraform, benefits, HCL basics
- [[02 - IaC Concepts]] — What is IaC, benefits, use cases
- [[03 - Core Terraform Workflow]] — init, plan, apply, destroy
- [[04 - Terraform Configuration]] — Resource blocks, data sources, meta-arguments
- [[05 - Variables & Outputs]] — Input variables, locals, output values
- [[06 - Terraform Modules]] — Module structure, sources, versioning
- [[07 - Terraform State]] — State management, backends, locking
- [[08 - Infrastructure Maintenance]] — Import, taint, lifecycle, workspaces
- [[09 - HCP Terraform]] — Workspaces, projects, remote runs, VCS integration
